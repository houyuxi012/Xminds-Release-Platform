# Xminds Release Platform 身份与用户中心交互原型设计

**日期：** 2026-08-14  
**状态：** 已确认原型设计  
**适用范围：** Xminds Release Platform P0 管理控制台交互原型  
**视觉基线：** Ant Design Pro v6.6.0  
**原型执行方式：** Open Design，Local Codex

## 1. 项目背景

现有 P0 设计已定义通用 OIDC、身份映射、平台角色、产品级权限隔离和不可篡改审计，但当前管理控制台原型尚未提供用户、组织架构、身份源及授权治理入口。单点登录只能完成用户认证，不能替代组织同步、角色授权、账号停用、产品范围控制和权限审计。

本次改版同时统一控制台的浅色视觉体系：左侧导航与所有业务详情抽屉均改为白色背景，并保持 Ant Design Pro v6 的导航层级、标题区、内容区和操作区分层。

## 2. 建设目标

1. 在控制台中补齐用户、组织、角色、产品授权和身份源管理能力。
2. 支持外部 SSO/身份平台自动同步与本地账户并存。
3. SSO 未启用时使用本地登录；SSO 启用后以 SSO 为主，仅保留受控应急本地登录。
4. 将身份变更、同步、授权和应急登录完整纳入日志中心。
5. 保持 P0 产品级隔离、自审批禁止和最小权限语义不变。
6. 形成可演示多个关联流程的精致交互原型，不在原型确认阶段实施生产代码。

## 3. 范围边界

### 3.1 本次包含

- 用户管理与用户详情；
- 外部组织架构同步与本地组织；
- 平台角色与产品范围授权；
- SSO 身份源配置、连接测试、属性映射及同步记录；
- 本地账户与应急管理员治理；
- 身份相关操作日志、登录日志与同步日志；
- 左侧导航与全局右侧详情抽屉白色化；
- 身份模式、同步、授权和异常状态的交互演示。

### 3.2 本次不包含

- 自建企业身份提供商；
- 在平台保存外部身份源用户密码；
- 替代外部身份源维护其组织主数据；
- 实现真实 SCIM、LDAP、OIDC 或 MFA 服务；
- 修改 Release、制品、可信目录、SCM 和分发领域状态机；
- 开始生产级前后端编码。

## 4. 设计原则

### 4.1 单一身份治理模型

外部同步用户、本地账户和应急账户统一映射为平台用户主体，使用相同的角色、产品范围、停用、审计和会话治理规则。身份来源不构成绕过授权策略的通道。

### 4.2 外部主数据优先

外部身份平台是同步用户姓名、邮箱、组织归属和启停状态的权威来源。平台只读展示这些字段，不允许直接修改；平台自主管理角色、产品范围和平台本地补充分组。

### 4.3 安全默认与可恢复性并重

启用 SSO 后禁止普通本地账户登录，但保留独立、强保护、可审计的应急管理员入口，避免身份平台故障造成永久锁死。SSO 故障不得自动降级为普通本地登录。

### 4.4 可审计与可追踪

身份源配置、同步、角色授权、本地账户、MFA、应急登录和账号状态变化必须生成结构化日志，并可从用户详情关联到日志中心。

## 5. 信息架构

左侧导航在现有分组之后新增“系统管理”分组：

| 菜单 | 职责 |
|---|---|
| 用户中心 | 管理用户列表、组织架构、本地账户及用户详情 |
| 角色与权限 | 管理平台角色、组织授权、用户授权和产品范围 |
| 身份源配置 | 管理 SSO 连接、属性映射、同步范围、同步策略和同步记录 |

### 5.1 用户中心

用户中心包含“用户管理”“组织架构”“本地账户”三个页签。

#### 用户管理

- 关键指标：用户总数、已启用、已停用、同步异常、应急账户；
- 筛选条件：关键词、身份来源、组织、平台角色、产品范围、同步状态、账号状态；
- 列表字段：用户、账号、身份来源、所属组织、平台角色、产品范围、同步状态、最近登录、账号状态；
- 点击用户打开右侧白色详情抽屉；
- 批量操作仅支持符合权限和来源规则的停用、授权或导出，不允许批量修改外部主数据。

#### 组织架构

- 左侧展示可搜索、可展开的组织树；
- 右侧展示组织摘要、负责人、直属成员、下级组织和授权摘要；
- 外部同步组织使用来源标识并保持只读；
- 支持平台本地组织，用于管理本地账户或补充平台授权分组；
- 删除本地组织前必须处理成员和继承授权。

#### 本地账户

- 展示普通本地账户与应急管理员；
- 支持创建、停用、设置有效期、重置 MFA 和凭据轮换；
- SSO 启用后，普通本地账户保留但显示“登录已禁止”；
- 应急账户显示高风险标识、最近验证时间和轮换到期时间；
- 禁止停用最后一个可用的应急管理员。

### 5.2 角色与权限

系统内置平台角色：

| 角色 | 核心权限 |
|---|---|
| 管理员 | 平台配置、身份映射、产品管理和授权治理 |
| 发布者 | 创建、提交和执行授权产品范围内的 Release |
| 审批者 | 审批授权产品范围内的 Release，但不得自审批 |
| 审计员 | 查询日志、查看关联事件并按权限导出证据 |
| 只读成员 | 查看授权产品范围内的资源与发布状态 |

授权支持用户和组织两个主体，范围支持全平台、指定产品、指定产品与通道。有效权限由可用授权取并集，显式拒绝优先；停用状态始终优先于授权结果。

### 5.3 身份源配置

身份源配置页面包含：

- SSO 状态与登录模式；
- 发行者、客户端、回调地址和证书等非敏感摘要；
- 连接测试与启用前检查；
- 用户和组织属性映射；
- 同步范围、过滤规则、周期和增量策略；
- 手动同步、最近同步结果和历史同步记录；
- 应急账户可用性检查；
- 禁用 SSO 的二次确认及影响说明。

目录同步优先展示 SCIM 2.0 标准能力。OIDC 仅承担认证，不假定能够提供完整目录；其他身份平台通过适配器扩展，原型不绑定具体厂商。

## 6. 身份模式状态机

| 状态 | 默认入口 | 本地账户行为 | 管理要求 |
|---|---|---|---|
| SSO 未启用 | 本地登录 | 普通与应急账户均按策略使用 | 管理员账户强制 MFA |
| SSO 配置中 | 本地登录 | 保持现状 | 可测试连接，不改变生产登录方式 |
| SSO 启用检查 | 本地登录 | 保持现状 | 连接测试、属性映射和应急账户检查全部通过 |
| SSO 已启用 | SSO 登录 | 普通本地账户禁止登录，仅应急账户可用 | 应急入口独立、强制 MFA、记录高风险日志 |
| SSO 故障 | SSO 错误页 | 不自动开放普通本地登录 | 管理员通过应急入口处理，不进行静默降级 |

启用或禁用 SSO 均属于高风险操作，需要二次确认、重新认证和完整审计。

## 7. 核心交互流程

### 7.1 启用 SSO

1. 管理员进入身份源配置；
2. 填写连接信息并测试；
3. 配置用户、组织和唯一标识属性映射；
4. 配置同步范围并执行预览同步；
5. 检查至少一个可用应急管理员；
6. 查看影响说明并二次确认；
7. 启用 SSO，后续普通用户默认进入 SSO 登录。

配置失败不得改变当前登录方式，避免误配置锁死平台。

### 7.2 用户与组织同步

1. 管理员触发手动同步；
2. 页面展示运行中状态与阶段进度；
3. 完成后展示新增、更新、停用、冲突和失败数量；
4. 点击结果打开白色详情抽屉；
5. 抽屉展示对象级差异、失败原因、重试建议和关联日志；
6. 冲突对象保持上次安全状态，不进行不可逆覆盖。

### 7.3 用户授权

1. 搜索并选择用户；
2. 打开白色用户详情抽屉；
3. 进入“角色与产品范围”；
4. 选择平台角色、产品和通道；
5. 页面展示授权变化摘要与风险提示；
6. 管理员二次确认后保存；
7. 生成操作日志，并可跳转日志中心查看。

### 7.4 创建本地账户

1. 管理员创建本地账户；
2. 设置有效期、平台角色、产品范围和本地组织；
3. 选择是否标记为应急管理员；
4. 应急管理员强制 MFA 和凭据轮换；
5. 系统生成一次性激活方式，敏感信息只展示一次；
6. SSO 已启用时，普通本地账户明确显示无法用于登录。

## 8. 右侧详情抽屉视觉规范

所有现有与新增右侧详情抽屉统一采用白色背景：

- 抽屉宽度根据内容采用 760 至 840px；
- 标题区、主体区、底部操作区均为白色；
- 分区使用 `#f0f0f0` 级别的浅灰边框，不使用深色面板；
- 页面遮罩保持低透明度中性色，确保主从层级清晰；
- 标题区包含对象名称、状态标签、来源和关闭入口；
- 主体使用 Descriptions、Tabs、Timeline、Alert 和紧凑表格组织信息；
- 固定底部仅保留当前上下文必要操作，高风险操作使用危险色与二次确认；
- 日志、产品、制品、Release、SCM、分发端点、用户和同步详情保持一致的抽屉语言。

## 8.1 左侧导航视觉规范

- 左侧导航、Logo 区和折叠控制区统一使用纯白背景；
- 导航与主内容区之间使用浅灰右边框，不使用深色分隔或阴影墙；
- 默认菜单文字与图标使用深灰色，分组标题使用中灰色；
- 当前菜单使用浅蓝背景、蓝色文字和蓝色图标，并保持足够对比度；
- 悬停菜单使用浅灰蓝背景，禁用项使用低对比度中性色；
- 折叠与展开状态均保持相同的白色视觉语言；
- 顶栏、左侧导航、主内容区和右侧详情抽屉共同形成完整浅色 Ant Design Pro v6 控制台；
- 不改变导航分组、菜单顺序、路由和权限可见性。

## 9. 数据与权限边界

原型使用以下概念对象表达身份治理关系：

- `UserPrincipal`：统一用户主体；
- `IdentitySource`：本地、SSO、应急等身份来源；
- `OrganizationUnit`：外部同步组织或平台本地组织；
- `RoleBinding`：用户或组织到角色和作用域的绑定；
- `SyncJob`：一次目录同步任务；
- `SyncConflict`：字段映射、唯一标识或组织归属冲突；
- `EmergencyAccessEvent`：应急认证及后续敏感操作记录。

外部主数据字段与平台授权字段分离，防止同步覆盖平台角色和产品授权。用户停用不删除历史 Release、审批和日志关联。

## 10. 安全与审计设计

- 本地管理员和应急管理员强制 MFA；
- 本地密码遵循强度、历史、有效期、失败锁定和登录限流策略；
- 密码、令牌、客户端密钥和恢复代码不得在列表、日志或导出中明文出现；
- 应急登录使用独立入口，不在普通登录页突出展示；
- 应急登录、身份源切换、角色授权、本地账户变更均触发结构化审计；
- 外部用户停用后立即拒绝新会话，并按策略撤销存量会话；
- 管理员不能通过组织授权绕过产品隔离；
- 审批者不得审批自己创建的 Release；
- 权限变更必须记录操作者、目标、变更前后摘要、时间、来源 IP 和请求 ID。

## 11. 异常与恢复设计

| 异常 | 处理方式 |
|---|---|
| SSO 连接测试失败 | 保持现有登录模式，展示可诊断错误和请求 ID |
| 属性映射缺失 | 阻止启用 SSO，定位缺失的必填映射 |
| 同步出现重复账号 | 不自动合并，进入冲突队列人工处理 |
| 外部组织被删除 | 先停用映射并展示受影响授权，不直接删除历史关系 |
| 最后一个应急管理员被停用 | 阻止操作并要求先建立替代账户 |
| SSO 运行时故障 | 展示故障页与支持信息，不自动开放普通本地登录 |
| 授权保存失败 | 不更新本地界面状态，保留编辑内容并提供重试 |
| 同步部分成功 | 显示成功与失败对象，允许针对失败项重试 |

## 12. 原型交互验收标准

- 左侧导航能够进入用户中心、角色与权限、身份源配置；
- 用户管理可筛选外部用户、本地账户和应急账户；
- 组织树与成员列表能够联动；
- 可打开用户白色详情抽屉并切换资料、授权、登录记录和操作日志；
- 可演示角色与产品范围授权及二次确认；
- 可演示 SSO 测试、启用检查、启用和故障状态；
- 可演示目录同步进度、统计结果、冲突和失败详情；
- 可创建本地账户并体现 SSO 启用后的登录限制；
- 禁止停用最后一个可用应急管理员；
- 身份相关操作能够关联至日志中心；
- 所有现有与新增右侧详情抽屉均为白色；
- 左侧导航、Logo 区和折叠控制区均为白色，当前项和悬停项状态清晰；
- 1280px 与 1440px 桌面视口下无横向溢出，关键操作无需水平滚动；
- 不展示任何完整密码、令牌、客户端密钥或恢复代码。

## 13. 风险分析

| 风险 | 影响 | 控制措施 |
|---|---|---|
| OIDC 被误认为目录同步协议 | 用户和组织数据不完整 | 明确认证与目录同步边界，优先采用 SCIM 2.0 |
| 本地账户绕过 SSO 策略 | 条件访问和离职停用失效 | SSO 启用后禁止普通本地登录，仅保留受控应急入口 |
| 双主数据冲突 | 用户属性和组织关系漂移 | 外部属性只读，平台仅维护本地组织与授权字段 |
| 组织授权扩大权限 | 发生越权 | 显式拒绝优先、产品范围校验和变更影响预览 |
| 身份源故障锁死平台 | 无法执行紧急发布或恢复 | 至少一个有效应急管理员、强制 MFA 和轮换检查 |
| 原型范围膨胀 | P0 交付延期 | 仅演示治理主流程，不实现身份协议与服务端逻辑 |

## 14. 结论

本设计以外部身份平台为主数据源，同时保留受控本地账户能力。SSO 未启用时使用本地登录；SSO 启用后默认使用 SSO，普通本地登录关闭，仅应急管理员通过独立入口访问。用户、组织、角色、产品范围、同步和审计形成闭环，并与现有 P0 的 OIDC、RBAC、产品隔离和日志中心设计保持一致。

本原型已获得确认，身份治理能力现作为 P0 正式实施基线的一部分。生产实现必须遵循 `2026-08-14-xminds-release-platform-p0-identity-log-baseline-design.md` 和 P0 总体实施计划；在用户明确批准进入实施前，不开始生产级编码。
